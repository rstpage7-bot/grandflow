# NEXORA Supabase Ready

واجهة عربية RTL لإدارة المشاريع، مجهزة لتعمل كملفات static على Vercel أو Netlify.

## المزايا
- إنشاء حساب وتسجيل الدخول باستخدام Supabase Auth.
- إنشاء المشاريع وتعديلها وحذفها.
- حالات المشروع: مخطط، قيد التنفيذ، مكتمل، متوقف.
- وصف وموعد تسليم وخطوات/مهام لكل مشروع.
- لوحة إدارة تظهر للمستخدم الذي يحمل role = `admin` وتعرض المشاريع على مستوى النظام.
- سياسات Row Level Security (RLS) في قاعدة البيانات.

## 1. تجهيز Supabase
1. أنشئ مشروعًا جديدًا في https://supabase.com/dashboard.
2. افتح SQL Editor ثم New query.
3. انسخ محتويات `supabase.sql` بالكامل واضغط Run.
4. من Project Settings > API Keys انسخ Project URL والمفتاح العام Publishable key أو anon key.
5. لا تستخدم `service_role` أو أي Secret key في الواجهة الأمامية.

## 2. ربط الموقع
1. افتح `index.html` محليًا للاطلاع على التصميم، لكن استخدم استضافة static لتجربة تسجيل الدخول بصورة موثوقة.
2. ارفع الملفات الخمسة (`index.html`, `style.css`, `app.js`, `supabase.sql`, `README.md`) إلى GitHub.
3. استورد المستودع في Vercel أو Netlify. لا يلزم Node.js أو build command؛ هذا موقع static.
4. افتح الموقع ثم اضغط «إعدادات الربط».
5. أدخل Project URL والمفتاح العام واضغط «حفظ والاتصال».

## 3. تفعيل حساب الإدارة
1. أنشئ حسابًا من صفحة الموقع وسجّل الدخول مرة واحدة كي ينشأ صف في `profiles`.
2. افتح Supabase > SQL Editor وشغّل الاستعلام التالي بعد استبدال البريد ببريدك:

   `update public.profiles set role = 'admin' where email = 'YOUR_EMAIL@example.com';`

3. سجّل الخروج ثم الدخول مرة أخرى. ستظهر لوحة الإدارة أسفل مساحة العمل.

**مهم:** لا تجعل أي مستخدم admin من الواجهة. تغيير الدور يتم من SQL Editor بواسطة مالك المشروع فقط.

## ملاحظات
- يجب تفعيل/ضبط تأكيد البريد في Supabase Authentication حسب ما يناسبك. إذا كان تأكيد البريد مفعّلًا، سيُطلب من المستخدم تأكيده قبل تسجيل الدخول.
- لوحة الإدارة تعرض المشاريع التي يسمح RLS لحساب الإدارة بقراءتها. لا تعتمد على إخفاء/إظهار الواجهة كحماية؛ الحماية الفعلية في سياسات قاعدة البيانات.
- النسخة الحالية تسجل قائمة الخطوات داخل جدول `tasks`. واجهة المشروع تحفظ الخطوات عند حفظ المشروع، لكن عرض المهام كتشيك ليست مستقلة غير مضاف في هذه النسخة.
- الملفات لم تُنشر على حساب استضافة، ولم يتم اختبار الاتصال بمشروع Supabase حقيقي. يلزم إدخال بيانات مشروعك وتجربة تسجيل الدخول بعد النشر.
